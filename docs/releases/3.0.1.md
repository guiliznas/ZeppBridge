# ZeppBridge 3.0.1

## 中文

- 新增：意大利语桌面界面，覆盖设置、健康数据、运动详情、AI 与训练计划、错误提示、新手引导、托盘菜单和登录窗口。
- 改进：更新包在后台静默下载；左上角绿色圆圈亮起后，点击图标即可安装并重启。更新完成后显示居中的更新说明，点击“知道了”后不再重复提醒。
- 修复：仅使用官方授权的账号，现在可以从已同步的运动记录识别手表；尚无设备记录时，不再误报“检测到未识别设备”。
- 修复：官方授权与高级数据认证分别显示状态，高级凭据失效时会明确提示重新认证。
- 修复：补连高级数据后立即同步新通道并刷新设备信息，避免被已有官方同步记录跳过。
- 改进：下载说明补充了 macOS 首次打开应用的操作步骤。

## English

- Added: Italian throughout the desktop app, including settings, health data, workout details, AI and training plans, errors, onboarding, the tray menu and the sign-in window.
- Improved: Updates download silently in the background. When the green ring around the top-left icon lights up, click it to install and restart. A centered release-notes dialog appears after the update; choose “Got it” to dismiss it permanently for that version.
- Fixed: Accounts using official authorization can now identify watches from synced workouts. An empty device list no longer incorrectly reports an unidentified device.
- Fixed: Official authorization and advanced-data credentials show separate connection states, with a clear reauthentication prompt when advanced credentials expire.
- Fixed: Connecting advanced data starts a sync for the new channel and refreshes devices, even when official data has already been synced.
- Improved: The download guide now includes the steps for opening the app for the first time on macOS.
